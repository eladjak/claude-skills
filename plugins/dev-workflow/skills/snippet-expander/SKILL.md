# Snippet Expander

Expand short abbreviations into full code snippets.

## Commands

| Command | Description |
|---------|-------------|
| `/snippet-expander <abbr>` | Expand abbreviation |
| `/snippet-expander list` | List all snippets |
| `/snippet-expander add <abbr>` | Add custom snippet |

## Built-in Snippets

| Abbr | Expands To |
|------|------------|
| `rfc` | React Functional Component |
| `us` | useState hook |
| `ue` | useEffect hook |
| `af` | Async function |
| `cl` | Console.log |
| `imp` | Import statement |
| `exp` | Export statement |
| `trycatch` | Try-catch block |

## Example

```
/snippet-expander rfc
→ Full React component code
```
