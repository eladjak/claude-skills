# Skill Search

Find the right skill for any task.

## Commands

| Command | Description |
|---------|-------------|
| `/skill-search <term>` | Search skills by keyword |
| `/skill-search list` | List all skills |
| `/skill-search info <name>` | Get skill details |
| `/skill-search tags` | Browse by category |

## Features

- Full-text search across skill descriptions
- Category filtering
- Trigger word matching
- Usage examples
