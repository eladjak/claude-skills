# ליאור, ברוכה הבאה לסקילים של Claude

כתב לך אלעד, ובכוונה בלי ז'רגון.

אספתי בשבילך כאן את מה שהכי מתאים לעבודה שלך: עריכת וידאו, תוכן לרשתות, כתיבה בעברית וקמפיינים. אין צורך לדעת תכנות. הכול נעשה בעברית רגילה: את כותבת ל-Claude מה את רוצה, והוא עושה.

---

## 1. מה זה סקיל, במילים פשוטות

סקיל הוא "דף הוראות" מוכן ש-Claude קורא לפני שהוא מתחיל לעבוד.

תחשבי על זה כך: אם תבקשי מעוזרת חדשה "תכתבי לי פוסט", היא תנחש איך. אם תתני לה קודם דף שמסביר "ככה כותבים לקהל ישראלי, ככה בונים קמפיין, ככה בודקים שזה לא נשמע כמו רובוט", התוצאה תהיה הרבה יותר טובה. סקיל הוא הדף הזה.

שלושה דברים טוב לדעת:

- **לא צריך להפעיל אותו ידנית.** Claude מזהה לבד מתי סקיל מתאים לבקשה שלך ומשתמש בו.
- **אפשר לבקש במפורש.** למשל: "השתמש בסקיל hebrew-writer".
- **זה לא משנה את Claude לצמיתות.** הסקיל פועל רק כשהוא רלוונטי לשיחה.

---

## 2. איזה חבילות מתאימות לך

הסקילים מסודרים בחבילות לפי נושא. בחרתי חמש. מתחת לכל אחת כתבתי למה היא מתאימה לך, שניים-שלושה סקילים, ובקשה לדוגמה שאפשר להעתיק.

### חבילה 1: `hebrew-rtl` (כתיבה ועריכה בעברית)

**למה היא בשבילך:** כשמודל כותב עברית, יש לו נטייה לשגיאות מוכרות ולניסוחים שנשמעים "מתורגמים" או "של בינה מלאכותית". החבילה הזאת בדיוק בשביל זה.

- `hebrew-writer`: כותב עברית שנשמעת כמו ישראלי אמיתי, ומזהה ומתקן ניסוחים שמסגירים שזה נכתב במכונה.
- `hebrew-ai-copy-edit`: עורך שפה. עובר על טקסט שכבר קיים, מתקן שגיאות מגדר ושגיאות נפוצות, ובודק כתיב מלא ותקינות לפי האקדמיה ללשון.
- `presentation-architect`: עוזר לבנות מצגת, צעד אחר צעד, עם שאלה אחת בכל פעם.

**בקשה לדוגמה:**
> כתוב לי פוסט אינסטגרם על ההשקה של הקורס החדש שלנו, בעברית טבעית, בלי ניסוחים שנשמעים כמו בינה מלאכותית. אחר כך תעבור עליו ותתקן כל דבר שנשמע מתורגם.

### חבילה 2: `israeli-skills` (שיווק ותוכן לשוק הישראלי)

**למה היא בשבילך:** יש בה סקילים שמכירים את הקהל והחוקים כאן: חגים, חוק הספאם, פלטפורמות מקומיות. החבילה גדולה (68 סקילים בנושאים כמו מסים ונדל"ן), ואת צריכה רק קומץ ממנה. את השאר Claude פשוט לא ישתמש בהם.

- `israeli-content-marketing`: אסטרטגיית תוכן לשוק הישראלי.
- `israeli-paid-ads`: קמפיינים ממומנים בגוגל ובמטא, כולל ניסוח מודעות בעברית.
- `israeli-email-sequences`: סדרות מיילים, עם התחשבות בחגים ובחוק הספאם הישראלי.
- `israeli-linkedin-strategy`: תוכן ללינקדאין בעברית ובאנגלית.

**בקשה לדוגמה:**
> אני מתכננת קמפיין לפני ראש השנה לעסק קטן. תציע לי רצף של שלושה מיילים, ותבדוק שאנחנו עומדים בחוק הספאם.

### חבילה 3: `israel-business` (שבת בתכנון, ותוכן לרשתות)

**למה היא בשבילך:** בעיקר בשביל סקיל אחד חשוב.

- `israeli-social-content`: תוכן לפייסבוק, אינסטגרם, טיקטוק ולינקדאין לקהל ישראלי: זמני פרסום, האשטגים בעברית, קבוצות פייסבוק.
- `shabbat-aware-scheduler`: מתזמן פרסומים ופגישות בלי להתנגש בשבת ובחגים.

**בקשה לדוגמה:**
> תבנה לי לוח תוכן לשבוע הבא לעמוד האינסטגרם של הלקוחה, שלושה פוסטים ושני סטוריז, ותזמן אותם כך שאף אחד לא יצא בשבת.

### חבילה 4: `ai-media` (וידאו, תמונות ותנועה)

**למה היא בשבילך:** את עורכת וידאו, ופה יש כלים לנסח הנחיות למחוללי וידאו, להכין תמונות ממוזערות, ולשלב כתוביות בתנועה.

- `seedance-master-prompt`: כותב הנחיות מפורטות וארוכות למחולל הווידאו Seedance (בנוי מ-14 חלקים: מצלמה, תאורה, תנועה, סאונד ועוד).
- `ai-thumbnail-cloning`: יצירה מחדש של תמונה ממוזערת (תמונת שער) בהשראת אחרת, כולל טקסט בעברית.
- `kinetic-video-creator`: סרטוני טקסט נע (כותרות שזזות) מתסריט.
- `pexels-broll`: מחפש סרטוני רקע חינמיים (ב-roll) באיכות גבוהה.

**בקשה לדוגמה:**
> כתבי לי הנחיה למחולל וידאו לקליפ של 8 שניות: קפה שנשפך בהילוך איטי בבוקר, תאורה חמה, מצלמה שמתקרבת לאט.

**שימי לב:** חלק מהכלים בחבילה הזאת דורשים חיבור לשירות חיצוני (למשל מפתח גישה לשירות קול או וידאו). ההנחיות עצמן (כמו `seedance-master-prompt`) עובדות מיד, וכלים כמו `kinetic-video-creator` ו-`pexels-broll` דורשים הגדרה קטנה. אם משהו לא עובד, Claude יסביר מה חסר.

### חבילה 5: `research-docs` (מחקר, תוכן ו-SEO)

**למה היא בשבילך:** כדי שהתוכן ימצא אותך בגוגל ובצ'אטים של בינה מלאכותית.

- `longtail-seo-content`: בונה עמודי תוכן סביב ביטויי חיפוש ספציפיים: שאלות, שאלות נפוצות, והסימון הטכני שמסביר לגוגל על מה העמוד.
- `geo-aeo-optimizer`: בודק שהאתר מוכן גם לבינות מלאכותיות שעונות על שאלות.

**בקשה לדוגמה:**
> אני כותבת תוכן לאתר של סטודיו לפילאטיס. תציע לי חמישה ביטויי חיפוש ארוכים, ותכתוב עמוד אחד מלא עם שאלות ותשובות.

> **אופציונלי:** אם תרצי לעבוד גם על עיצוב דפי נחיתה ומצגות, יש חבילה שנקראת `design-ui`. כדאי להתחיל בלעדיה.

## 3. התקנה ב-Claude Code

אם את עובדת עם Claude Code (התוכנה שרצה בשורת הפקודה):

1. פותחים את Claude Code (כותבים `claude` בטרמינל).
2. מעתיקים, מדביקים ולוחצים Enter:

```
/plugin marketplace add eladjak/claude-skills
```

3. מתקינים את החבילות שבחרת, אחת אחרי השנייה:

```
/plugin install hebrew-rtl@eladjak-skills
/plugin install israeli-skills@eladjak-skills
/plugin install israel-business@eladjak-skills
/plugin install ai-media@eladjak-skills
/plugin install research-docs@eladjak-skills
```

4. סוגרים ופותחים שוב את Claude Code, או מקלידים `/reload-plugins`.

זהו. מכאן Claude משתמש בסקילים לבד כשהם מתאימים.

**טיפ:** כתבי ל-Claude "אילו סקילים יש לי ומה כל אחד עושה?", והוא יסביר.

**עדכון בעתיד:** `/plugin marketplace update eladjak-skills`

## 4. התקנה ב-claude.ai (באתר או באפליקציה)

אם את עובדת עם Claude באתר או באפליקציית שולחן העבודה, אפשר להעלות סקיל אחד בכל פעם, כקובץ zip.

**מה הכנתי לך:** תיקייה בשם `docs/lior-zips/` עם עשרה קובצי zip מוכנים, אחד לכל סקיל:

| קובץ | מה הוא עושה |
|---|---|
| `hebrew-writer.zip` | כתיבה בעברית טבעית |
| `hebrew-ai-copy-edit.zip` | עריכת שפה והגהה בעברית |
| `israeli-social-content.zip` | תוכן לרשתות חברתיות |
| `israeli-content-marketing.zip` | אסטרטגיית תוכן |
| `israeli-paid-ads.zip` | קמפיינים ומודעות |
| `israeli-email-sequences.zip` | סדרות מיילים |
| `israeli-linkedin-strategy.zip` | לינקדאין |
| `seedance-master-prompt.zip` | הנחיות למחולל וידאו |
| `presentation-architect.zip` | בניית מצגת |
| `longtail-seo-content.zip` | תוכן שמוצאים בגוגל |

**איך מעלים:**

1. נכנסים ל-claude.ai ולוחצים על השם שלך ואז על **Settings** (הגדרות).
2. נכנסים ל-**Capabilities** (יכולות).
3. מחפשים את **Skills**. אם יש מתג להפעלת ביצוע קוד ויצירת קבצים (Code execution), מדליקים אותו.
4. לוחצים **Upload skill** ובוחרים את קובץ ה-zip.
5. מדליקים את המתג ליד הסקיל.

מעכשיו אפשר לכתוב בשיחה בקשה רגילה, או לציין את שם הסקיל.

**שימי לב:**
- מעלים כל zip בנפרד.
- אם את לא רואה את Skills בהגדרות, ייתכן שהתכונה עדיין לא פתוחה בתוכנית שלך. כתבי לי ואבדוק איתך.
- בחרתי בשביל claude.ai סקילים שמבוססים על הוראות כתובות. לחלקם יש גם סקריפטים קטנים שעוזרים, והם פועלים רק כשביצוע קוד מופעל. בלעדיהם הסקיל עדיין עובד.
- סקילים של יצירת תמונות ווידאו בפועל (כמו `ai-thumbnail-cloning`) כדאי להשאיר ל-Claude Code, שם יש להם גישה לכלים.

## 5. אם משהו לא עובד

**"אני לא רואה את הסקילים אחרי ההתקנה ב-Claude Code".**
סגרי ופתחי את Claude Code, או כתבי `/reload-plugins`. אם עדיין לא, כתבי `/plugin` ובדקי שהחבילה מופיעה ברשימה כמותקנת.

**"הפקודה `/plugin marketplace add` לא עובדת".**
ודאי שכתבת אותה בדיוק כמו שהיא, כולל `eladjak/claude-skills` ובלי רווחים מיותרים. ודאי שהתוכנה מעודכנת.

**"ב-claude.ai ההעלאה נכשלה".**
בדקי שהעלית קובץ zip אחד ולא תיקייה. אם עדיין לא, נסי דפדפן אחר או רענון, ובדקי שהקובץ לא ריק.

**"Claude לא משתמש בסקיל שהתקנתי".**
בקשי ממנו במפורש: "השתמש בסקיל hebrew-writer". לפעמים הוא לא מזהה לבד כשהבקשה מנוסחת באופן כללי מדי.

**"הכתיבה עדיין נשמעת לא טבעית".**
תני לו דוגמה. הדביקי טקסט קצר שאת אוהבת ואמרי: "ככה אני רוצה שזה יישמע". זה משפר מאוד.

**"הסקיל מבקש מפתח או חיבור שאין לי".**
זה קורה רק בסקילים שמחוברים לשירות חיצוני (למשל וידאו או קול). אל תתקעי עם זה, כתבי לי ונחליט אם זה בכלל שווה את המאמץ.
